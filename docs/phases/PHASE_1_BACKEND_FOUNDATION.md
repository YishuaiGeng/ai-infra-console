## Technical decisions

| Area | Decision | Reason |
| --- | --- | --- |
| API | FastAPI with `/api/v1` routers | Matches the product architecture and produces OpenAPI documentation |
| Database | PostgreSQL with SQLAlchemy 2 async sessions | Production target with explicit transaction boundaries |
| Migration | Alembic | Versioned, reviewable schema changes |
| Cache and jobs | Redis plus RQ | Small operational surface for the first background worker |
| Authentication | Username/password with short-lived JWT bearer tokens | Stateless MVP suitable for the web console and API clients |
| Password hashing | Argon2 through `pwdlib` | Modern password hashing without custom crypto |
| Identifiers | UUID values generated by the application | Stable across Central API and future Agents |
| Local tooling | `uv`, Ruff, mypy, pytest | Reproducible Python environment and fast checks |
| Tests | Async API tests with isolated SQLite and fake Redis dependencies | Deterministic unit/integration coverage without weakening PostgreSQL runtime checks |
